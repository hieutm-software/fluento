## 🧩 Tính năng chính

- 🛤️ **Lộ trình học 291 ngày** — Học tuần tự từ Day 1 với Flashcard, bài kiểm tra mỗi ngày, theo dõi Streak và đấu trường **Endless Arena**.
- 📖 **Từ điển Offline** — 5.823 mục từ dùng hoàn toàn ngoại tuyến kèm nhãn CEFR (`A1`–`C2`), phiên âm IPA Anh/Mỹ, ví dụ và phát âm.
- 🌐 **Dịch song ngữ & Phản xạ AI** — Dịch Anh ⇄ Việt với 3 chế độ **Standard**, **Reflex (`/situ`)**, **Tech / IT (`/it`)** qua Google Translate miễn phí hoặc API key Gemini / Groq cá nhân (BYOK).
- 🎧 **Luyện Nghe & Phát âm** — Bộ bài nghe theo cấp độ CEFR `A1`–`C2`, tùy chỉnh tốc độ đọc TTS, ghi âm và chấm phát âm.
- 🎨 **Giao diện Sáng / Tối đồng bộ** — Tông Carbon Neutral & Indigo-Periwinkle dễ nhìn trên cả Light/Dark Mode, hỗ trợ chuyển ngôn ngữ `EN` / `VI`.

## 📲 Hướng dẫn cài đặt

1. Tải file `app-release.apk` mới nhất tại [GitHub Releases](https://github.com/hieutm-software/fluento/releases).
2. Mở file APK trên điện thoại Android (cấp quyền *Cài đặt ứng dụng không rõ nguồn gốc* nếu được hỏi).
3. *(Tùy chọn)* Nhập API key Gemini hoặc Groq cá nhân trong mục **Settings** nếu muốn dùng chấm phát âm AI và dịch ngữ cảnh nâng cao.
