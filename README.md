## 🧩 Core Features

- 🛤️ **291-Day Learning Path** — Sequential daily curriculum starting from Day 1 with Flashcards, Daily Tests, Streak tracking, and **Endless Arena** arcade challenges.
- 📖 **Offline Dictionary** — 5,823 offline entries with CEFR levels (`A1`–`C2`), UK/US IPA phonetics, definitions, examples, and audio pronunciation.
- 🌐 **Bilingual Translation Studio** — Instant EN ⇄ VI translation across **Standard**, **Reflex (`/situ`)**, and **Tech / IT (`/it`)** modes using free Google Translate or your own Gemini / Groq API key (BYOK).
- 🎧 **Listening & Speaking Practice** — CEFR `A1`–`C2` listening drills, adjustable TTS reading speed, voice capture, and speech recognition feedback.
- 🎨 **Adaptive Light & Dark UI** — Crisp Carbon Neutral & Indigo-Periwinkle interface with built-in `EN` / `VI` language switching.

## 📲 Installation

1. Download the latest `app-release.apk` from [GitHub Releases](https://github.com/hieutm-software/fluento/releases).
2. Open the APK on Android (allow *Install unknown apps* if prompted).
3. *(Optional)* Add a personal Gemini or Groq API key in **Settings** to unlock AI pronunciation scoring and contextual translation.
